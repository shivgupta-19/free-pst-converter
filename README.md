# Recoveryfix Free PST Converter



**Recoveryfix Free PST Converter** is a standalone Windows desktop utility designed to convert Outlook PST files into multiple accessible file formats without requiring Microsoft Outlook to be installed. Convert PST data up to **500 MB** for free while keeping your original folder hierarchy, email properties, and attachments intact.

---

## ✨ Key Features

* **Standalone Conversion:** Convert single or multiple PST files without installing or configuring Microsoft Outlook.
* **Multiple Output Formats:** Export PST data to **PDF, EML, MSG, MBOX, CSV, DOCX, DOC, XLSX, HTML, and MHT**.
* **Complete Mailbox Preview:** Inspect emails, contacts, calendars, tasks, and original folder structures before running the export.
* **Auto-Locate PST Files:** Automatically scan and detect `.pst` files stored across your local drives.
* **Granular Data Filtering:** Filter specific items using **Start Date / End Date** ranges, item types, or search parameters (From, To, Subject, etc.).
* **Attachment & Email Extraction:**
  * Extract and save all email attachments separately to a local folder (with or without file extensions).
  * Extract email addresses directly into **XLSX, CSV, or Outlook Native CSV** formats.
* **Conversion Log Report:** Generates a detailed summary report after the conversion process completes.

## 🚀 How to Use

1. **Download & Install:** Download the installer from the official [Recoveryfix Free PST Converter](https://free.recoveryfix.com/pst-converter/) page and install it on your Windows PC.
2. **Add PST Files:** Launch the software and click **Add File(s)** to browse manually, or use the auto-search feature to locate PST files on your system.
3. **Preview & Select:** Expand the mailbox tree to preview emails and select the specific folders you wish to export.
4. **Choose Format & Filters:** Click **Export**, pick your desired output format (e.g., PDF, EML, MSG, MBOX), and apply optional date or item filters.
5. **Save Output:** Specify a destination folder on your system and start the conversion.
